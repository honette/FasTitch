複数の画像を放り込んだら、右側にどんどん連結して1枚にしたい。
1つ目の画像を基準に Height は揃える。
連結後の画像のアスペクト比が 16:9 より横長にならないように自動調整する。
自動調整っていうのは、各画像の左右をトリミングして細くすること。

まだ細かいことは決めてない。機能は最小限でいい。
Windows 11 で起動できるアプリ (.exe) にする。
前に作った FasTrim と同じく Python + PySide6 + Pillow、UI は英語でいいはず。
Windows での作業は Git Bash 前提。

思いついてる流れはこんな感じ:
- 画像を複数ドロップ（または開く）
- 1枚目の高さに、あとの画像の高さを合わせる
- 横に連結する
- 連結結果が 16:9 より横長なら、各画像の左右を切って幅を削る
- 1枚の画像として別名保存

決まってないこと（実装で勝手に固めないで、必要なら聞いて）:
- 並び順（ドロップ順? ファイル名? あとから並べ替え?）
- 高さ揃えは拡大縮小で合わせるのか、上下クロップなのか
- 左右トリムは中央基準で均等か、別の寄せ方か
- 何枚あっても 16:9 に収めるために、各画像から同じ幅を削るのか、比率で按分するのか
- 最初から 16:9 以下ならトリムしないのか
- 1枚目自体がすでに 16:9 より横長なときどうするか
- 画像の間に隙間を入れるか
- 保存名や保存先、出力形式
- プレビューの見せ方、並びの編集 UI
